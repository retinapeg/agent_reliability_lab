# roman_to_int

Implement `roman_to_int(s: str) -> int` in `solution.py`.

- Accept only canonical uppercase Roman numerals for 1 to 3999 (the form produced by the standard
  subtractive notation: `IV`, `IX`, `XL`, `XC`, `CD`, `CM`).
- Raise `ValueError` for anything else, including non-canonical forms (`"IIII"`, `"VV"`, `"IC"`,
  `"VX"`, `"MMMM"`), lowercase input, and the empty string.
